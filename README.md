# KbmShare —— 一套键鼠管两台 Windows

自研的迷你"软件 KVM"（Mouse Without Borders 平替）。两个 exe、一条 TCP 连接，
实现：鼠标冲屏幕边缘自动切换控制、键盘跟随、文本剪贴板双向同步。

## 快速开始

1. **构建**（在本机执行一次）：双击 `build.bat`，生成 `KbmShare.exe`。
   把 `KbmShare.exe` 拷到第二台机器（无需安装任何运行时，Win10/11 自带 .NET Framework）。

2. **左边那台**（通常接着键盘鼠标的那个），管理员 CMD 运行（也可以直接双击 exe，按菜单选 1）：
   ```
   KbmShare.exe left
   ```
   启动后会打印本机 IP。首次运行弹出防火墙提示时点 **允许**（勾选专用网络）。

3. **右边那台**，管理员 CMD 运行（IP 换成左边机器打印的）：
   ```
   KbmShare.exe right 192.168.1.10
   ```
   两边日志出现 `已连接到: ...` 即成功。

## 日常操作

| 动作 | 效果 |
|---|---|
| 鼠标冲向屏幕（左机的右/右机的左）边缘并继续外推 | 控制权切到对方机器，键盘跟着走 |
| 在被控机器上把光标冲回相反边缘 | 控制权切回来 |
| 动任意一台机器自己的物理键鼠 | 该机器立即接管（从对方手里抢回） |
| 右Ctrl + F12 | 强制把控制权拉回本机（逃生舱） |
| Ctrl+C | 退出程序（在任意一台） |
| 复制文本 / 截图 | 自动同步到另一台的剪贴板，直接 Ctrl+V |

## 参数

```
KbmShare.exe left | right <对方IP>  [--port 4123] [--speed 1.0] [--nohooks]
```

- `--port`：TCP 端口，两边一致
- `--speed`：控制对方时光标移动倍率（远程通道绕过了 Windows 指针加速，
  如果觉得远程时鼠标变快/变慢，用这个调，比如 0.7 或 1.5）
- `--nohooks`：只跑网络层不装钩子，调试连通性用

## 防火墙（连不上时看这里）

left 机器需要放行入站 TCP 4123。管理员 CMD：

```
netsh advfirewall firewall add rule name="KbmShare" dir=in action=allow protocol=TCP localport=4123
```

## 工作原理

- **捕获**：低级钩子 `WH_MOUSE_LL` / `WH_KEYBOARD_LL` 全局拦截物理输入；转发期间钩子
  返回 1 吞掉事件，本机不响应
- **增量**：光标钉在屏幕边缘后钩子坐标不再变化，所以用 Raw Input（`WM_INPUT`）取
  未钳制的鼠标增量 —— 这是冲边切换能流畅工作的关键
- **传输**：TCP + `TCP_NODELAY`（关 Nagle），紧凑二进制帧，发送侧批量合并、
  心跳保活，队列积压自动判定死连接
- **注入**：对端用 `SendInput` 注入（键盘走扫描码，兼容性最好），注入的事件带
  INJECTED 标记，不会被自己的钩子二次转发（无回环）
- **防误触**：贴边后连续 2 次仍向外推才切换，路过边缘不会误切

## 已知限制（原型版）

- 只按**主显示器**的边缘和坐标计算，多屏用户暂不适用
- 控制管理员/UAC 窗口需要两边都以管理员运行
- 部分游戏（Raw Input + 反注入）不响应注入的输入
- 断连瞬间如果正按着 Shift/Ctrl 等修饰键，对端可能卡键状态，按一下对应键即可恢复
- 剪贴板同步文本和图片（DIB 格式，截图/网页图片直接粘贴），上限 48MB；文件形式的复制未实现
- 蓝牙键鼠若与两台机器都有配对记录，请确保只连着一台，否则输入会被系统分流

## 故障排查

- **连不上**：两台机器能否互相 ping 通；left 机器防火墙是否放行 4123
- **用一会儿键鼠"失灵/穿透"**：Windows 会静默摘除响应过慢的低级钩子，
  重启程序即可；确保不要同时跑多个同类软件（Synergy/Barrier/MWB 等）
- **切换没反应**：看控制台日志，`光标冲出边缘` / `对方光标进入本机屏幕`
  等状态转换都会打印，能直接定位卡在哪一步
